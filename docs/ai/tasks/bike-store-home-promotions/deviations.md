## Наблюдения и действия по ходу работы

1. **Ранее главная не имела `h1`.**
   - Ожидалось (отзыв проверки Sol): у главной есть настоящий заголовок.
   - Наблюдается: до правки заголовок слайда был `<span class="hero-title">`, поэтому
     на главной не было ни одного `h1`.
   - Действие: заголовок слайда заменён на `<h1 class="hero-title">` внутри
     единственной ссылки слайда; `.hero-copy` изменён со `<span>` на `<div>`, чтобы
     вложить заголовок валидно (содержимое ссылки — flow content). CSS
     `.hero-title` получил `margin: 0` и сохранённый font-size, чтобы отступы/кегль
     не изменились. Скрытые слайды остаются `hidden` (вне отображения и фокуса),
     поэтому в дереве доступности виден один `h1`.
   - Доказательство: `prototype/storefront.mjs:150-161`; проверка
     `home hero uses one whole-slide link per slide and no All products CTA`
     требует `<h1 class="hero-title">` в каждом слайде.

2. **Кровотечение clamp в карточке статьи и дефолтное оформление ссылки.**
   - Ожидалось (отзыв проверки Sol): preview не показывает частичную пятую строку;
     карточка статьи не выглядит как дефолтная ссылка (подчёркивание по всей карточке).
   - Наблюдается: `.article-preview` имел `padding-bottom: 16px` на том же
     `-webkit-box` с `-webkit-line-clamp: 4` (известное кровотечение пятой строки);
     `.latest-card` наследовал подчёркивание ссылки на изображении/дате/заголовке/body.
   - Действие: нижний отступ перенесён на карточку (`.latest-card { padding-bottom: 16px }`),
     у preview оставлено `padding: 0 14px` и добавлен страховочный
     `max-height: calc(4 * 1.5em)`. Карточке заданы `text-decoration: none`,
     `color: var(--ink)`, нейтральная рамка/радиус, hover/focus; подчёркивание только
     у заголовка на hover. Все правила ограничены селекторами `.latest-card`, поэтому
     существующий список журнала (`#journal`) не изменён.
   - Доказательство: `prototype/styles.css` (блок `Latest journal cards`);
     общих правил `.article-card` не добавлено. Проверка
     `home shows the three latest published articles before the footer` не менялась.

3. **Мобильная читабельность белого текста на светлой сцене.**
   - Ожидалось (отзыв проверки Sol): eyebrow главного слайда и eyebrow промокарточки
     читаемы на мобильном поверх светлой локальной сцены.
   - Наблюдается: верх градиента `to top` имел opacity 0.04, поэтому белый текст у
     верха копии терялся на светло-серой иллюстрации.
   - Действие: усилен тёмный оверлей без изменения акцентного синего и локальной
     иллюстрации: `.hero-copy` — `0.72 / 0.45 / 0.40` (низ/середина/верх),
     `.promo-copy` — `0.72 / 0.45 / 0.40`. Layout, размеры и цвета не менялись.
   - Доказательство: `prototype/styles.css:164,188`.

## Непроверенное

- Реальная браузерная приёмка (desktop 1440/1024, 768/390/360, пропорции 70/30,
  равенство промо, отсутствие переполнения, клики по слайду/карточкам, читабельность
  на мобильном) остаётся за Sol; в этой задаче выполнены только
  поведенческие/синтаксические проверки.
