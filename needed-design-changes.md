Общее инфо по дизайну:
- минимум цветов, шрифтов. Не использовать элементы дизайна, которые не встречаются в реальных примерах онлайн-магазинов
- конркетно по шрифтам - должен быть 1 основной шрифт, который применяется в основном для текста. Предпочтительно указать sans-serif шрифт, который выглядит базово и быстро загружается, можно использовать системный, даже более предпочтительно для скорости. Акцентный шрифт тоже должен быть sans-serif подобным, шрифты с засечками избегать полностью. 2 шрифта на весь проект, больше НЕЛЬЗЯ
- Пастельное сочетание цветов, которое есть сейчас - ужасно, так как это слишком похоже на AI slop. Ничего страшного, если сайт будет выглядеть как один из референсов по цветам. Можно использовать даже #fff фон для сайта пока что. Всего из таких явных акцентных цветов можно сделать 3 - белый или близкий нейтральный off-white, черный или off-black цвет и акцентный цвет. Его я представляю как что-то более менее приближенное к голубому/синему, он будет встречаться явно меньше остальных. И все эти предложения по цветам НЕ означают, что на сайте не может быть других цветов. МОГУТ! Но там, где это помогает дать контраст конркетному элементу
